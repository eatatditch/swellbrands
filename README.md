# swellbrands.co

Marketing site for Swell Brands — the parent company of Ditch, Swell Surf Co., and what's coming next.

## Stack
- GitHub (source)
- Vercel (hosting, auto-deploy from main)
- Supabase (newsletter signups)

## Editing
- Browser: open this repo on GitHub and press `.` to launch github.dev
- Terminal: git pull, edit index.html, git push
- AI: run `claude` in this directory

## Local preview
Open index.html directly in a browser. No build step.

## Newsletter signups
View at app.supabase.com → Table Editor → subscribers
